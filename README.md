# 柔道スコアカム

試合を撮影しながら、試合時間・スコアを記録し、数秒前の映像をすぐに見返せるスマホ用 Web アプリ（PWA）です。

## できること
- **撮影**：スマホのカメラで録画。時計とスコアを映像に焼き込み（設定でオフ可）。保存すると写真アプリに保存されます（共有メニュー →「ビデオを保存」）
- **試合時計**：はじめ／まて、残り時間、時間終了時の同点はゴールデンスコアへ自動移行、ブザー
- **抑込**：白／青の抑込タイマー。秒数に応じて一本・技あり・有効を自動付与（秒数は設定で変更）
- **スコア**：一本・技あり・有効・指導・反則負け。合わせ技一本、指導3で反則負けを自動判定。「取消」で1つ前に戻せます
- **ビデオ確認**：「リプレイ」で 5／10／15／30 秒前から再生（録画は止まりません）。¼倍・½倍スロー、コマ送り
- **試合記録**：スコアごとに時刻を記録。記録の「映像」を押すとその場面の5秒前から再生

## スマホで使うには
カメラは **https のページ** でしか動かないため、このフォルダを Web に置いて開きます。

1. GitHub Pages や Netlify などの無料ホスティングに、このフォルダの中身（index.html ほか全ファイル）をアップロード
2. スマホのブラウザ（iPhone は Safari、Android は Chrome）でその URL を開く
3. 共有メニュー →「ホーム画面に追加」でアプリのように起動できます（2回目以降はオフラインでも起動）

## 注意
- 映像は端末のメモリ上にだけ保持され、外部には送信されません。ページを閉じると消えるので、必要な試合は「保存」してください
- 長時間撮り続けるとメモリを多く使います。1試合ごとに「保存」→「次の試合」がおすすめです
- 試合ルール（有効の有無、合わせ技一本、抑込の秒数など）は大会の規定に合わせて「設定」で変更してください
